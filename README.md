# Reusable AI Agent Harness

A Python-based AI agent harness designed to support
multiple applications.

## Project Goals

- Learn how LLM APIs work
- Implement an agent execution loop
- Build a reusable tool-calling system
- Support multiple LLM providers
- Add memory, logging, and error handling
- Develop a job application manager
- Develop a gaming hub agent

## Technology Stack

- Python
- Git and GitHub
- OpenAI API (initial provider)
- Pydantic
- pytest
